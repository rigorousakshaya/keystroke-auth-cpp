#  Keystroke Authentication System (C++)

This project implements a **behavior-based authentication system** using
**keystroke dynamics**.  
User login is verified not only by password, but also by **typing pattern**.

---

##  Features
- User Registration
- Keystroke timing capture
- Secure Login
- Dashboard after login
- Store private data (marks)
- View stored data
- File handling
- Multiple line input support

---

##  Technologies Used
- C++
- File Handling
- Chrono library
- Vectors
- VS Code
